📊 SalesData Power BI Dashboard

📂 Project Overview
The SalesData Dashboard provides an insightful and interactive view of sales performance across time, geography, and products. It leverages key visualizations to help business users analyze trends, identify high-performing segments, and make data-driven decisions.

🖼️ Visuals Added
1. 📈 Line Chart
• Purpose: Displays the total Sales (Sum of Price) over Monthyear.
• Insight: Reveals monthly sales trends and patterns over time.
2. 📊 Bar Chart
• Purpose: Illustrates Sales by State.
• Insight: Enables comparison of regional sales performance.
3. 🍩 Donut Chart
• Purpose: Shows Sales by Product.
• Insight: Highlights contribution of each product to overall sales, with percentage breakdowns.

🎛️ Interactive Filters (Slicers)
• State Selector: 🌍 Filter the dataset by selecting different States/Provinces.
• Product Selector: 📦 Focus the analysis on specific Products.
These slicers allow dynamic exploration and create a personalized experience for end-users.

🎨 Color Highlighting
Top-performing States and Products are emphasized with distinctive colors 🔥, making high-value insights immediately visible at a glance.

🚀 How to Use
1. Open the `salesdata.pbix` file in Power BI Desktop.
2. If required, refresh the data 🔄.
3. Use the tabs and slicers to navigate through different insights 🧭.
4. Hover over charts to see detailed tooltips 📌.

📋 Requirements
• Software: Power BI Desktop (latest version recommended)
• Permissions: Ensure you have access to the underlying data if connected to live sources.
